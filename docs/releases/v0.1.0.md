# v0.1.0

## What this release is

`v0.1.0` is the first release-ready cut of `workflow-auto` as the host
repository for the reusable `workflow-base` template.

It focuses on making the template auditable, verifiable, copyable, and safe to
adopt without adding a second workflow system.

## What is included

- canonical `.agents/skills/goi-workflow/SKILL.md`
- `.codex` and `.claude` thin compatibility shims
- OpenSpec wrapper skills and archived `harden-template-contracts` change
- workflow docs under `docs/ops/workflow/`
- `scripts/check-host-workflow-deps.sh`
- `scripts/verify-workflow-template.sh`
- pytest contract coverage, including bootstrap contract tests
- GitHub Actions verification in `.github/workflows/verify.yml`
- clarified `workflow-auto` host identity vs reusable `workflow-base` template

## How to verify locally

Run:

```text
scripts/check-host-workflow-deps.sh
scripts/verify-workflow-template.sh
./.venv/bin/pytest -q
openspec validate --specs
```

## How to copy or adopt the template

1. Copy the reusable template surfaces into the new repository.
2. Replace the host-specific identity in `README.md`.
3. Replace the current-mainline inventory in
   `openspec/specs/project-mainline-routing/spec.md`.
4. Keep `.agents/skills/goi-workflow/SKILL.md` canonical.
5. Keep `.codex` and `.claude` GOI entries as thin shims only.
6. Run the local verification chain before treating the copied repo as ready.

  enforced runtime change.
