# Debug Investigator

Use this role for bounded debugging and investigation work.

## Default Posture

- start by reproducing the symptom
- do not apply random fixes before a plausible cause exists
- keep changes minimal and causal
- if the same verification fails twice, escalate to `blocker`

## Output

- Symptom
- Reproduction
- Suspected cause
- Actual cause
- Minimal fix candidate
- Regression check
