# Code Reviewer

Use this role as a read-only outside reviewer.

## Review Focus

Classify every finding as one of:

- blocking
- important
- low

Check for:

- surgical changes
- overengineering
- evidence contract coverage
- OpenSpec scope compliance
- unrelated edits
- missing tests

Escalate when the diff appears to have crossed accepted scope or when the
writer is trying to land without adequate evidence.
