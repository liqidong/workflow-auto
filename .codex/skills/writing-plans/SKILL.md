# Planning Compatibility Shim

For this repo, canonical planning lives in OpenSpec artifacts rather than a
separate mandatory planning chain.

Use:

- [`.agents/skills/goi-workflow/SKILL.md`](../../../.agents/skills/goi-workflow/SKILL.md) to choose the route
- [`.codex/skills/openspec-propose/SKILL.md`](../openspec-propose/SKILL.md) to create proposal, design, and tasks
- optional `plan-*` review skills when architecture, product, design, or DX
  critique is warranted

This shim does not create a second planning system outside OpenSpec.
